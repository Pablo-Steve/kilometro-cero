# Kilómetro Cero

Web de coches y motos: catálogo por generaciones, fichas con fallos típicos, simulador de costes, mecánica, comparador, rutas por Madrid y alrededores, diseñador de rutas, quiz, técnicas de conducción y test de perfil.

- `data/` – datos (coches, motos, motores, rutas, contenido). Para añadir modelos basta con añadir líneas.
- `js/` – la aplicación y las ilustraciones.
- `fotos/` – fotos reales de Wikimedia Commons con autor y licencia (`creditos.json`). Las descarga la acción **Descargar fotos reales** (`.github/workflows/fotos.yml`) a partir de `tools/lista.txt`.
